🚀 MULAI CEPAT (2 LANGKAH):

=== OPSI A: DEPLOY KE VERCEL (RECOMMENDED) ===

1. Install Vercel CLI
   → npm install -g vercel

2. Deploy (Icon SVG sudah included!)
   → vercel --prod
   → Aplikasi live dalam 2 menit!

📚 Panduan: VERCEL-QUICKSTART.md

=== OPSI B: JALANKAN LOKAL ===

1. Jalankan Server (Icon SVG sudah included!)
   Windows: Double-click start-server.bat
   Mac/Linux: ./start-server.sh
   Manual: python -m http.server 8000

2. Buka Browser
   → http://localhost:8000

Optional: Generate PNG icons untuk kompatibilitas maksimal
   → Buka: generate-png-icons.html di browser

🎯 CARA PAKAI:

➕ Tambah Jadwal
   Klik tombol ➕ → Isi form → Simpan

✏️ Edit Jadwal
   Klik tombol ✏️ pada kartu jadwal → Edit → Simpan

🗑️ Hapus Jadwal
   Klik tombol 🗑️ pada kartu jadwal → Konfirmasi

🔔 Alarm
   Klik tombol 🔔 untuk lihat alarm aktif
   Izinkan notifikasi saat diminta!

📅 Kalender
   Klik tanggal → Otomatis scroll ke jadwal

📊 Filter Bulan
   Klik nama bulan untuk ganti tampilan

⚠️ PENTING:

! Icon harus di-generate dulu (create-icons.html)
! Gunakan HTTP server, bukan file:// protocol
! Izinkan notifikasi untuk alarm
! Jangan clear browser data (data akan hilang)

🐛 TROUBLESHOOTING:

❌ Server tidak jalan?
   → Install Python atau gunakan VS Code + Live Server

❌ Notifikasi tidak muncul?
   → Cek permission di browser settings

❌ Icon tidak ada?
   → Generate ulang dengan create-icons.html

❌ Data hilang?
   → Jangan clear browser cache/localStorage
